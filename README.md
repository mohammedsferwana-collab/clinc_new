# مركز الأمل الطبي — نظام إدارة العيادة

استقبال ← عيادة ← صيدلية ومخزون ← تقارير يومية/أسبوعية/شهرية، مع استيراد السجلات القديمة من إكسل، ونسخ احتياطي شامل لكافة البيانات.
الواجهة ملفات ثابتة (بدون خطوة بناء) تتصل مباشرة بـ Supabase، وتُنشر على Vercel.

## 1) إعداد Supabase (10 دقائق)
1. أنشئ مشروعاً جديداً في supabase.com.
2. افتح **SQL Editor ← New query**، والصق محتوى `supabase/schema.sql` كاملاً، ثم **Run**.
2.ب. بعدها شغّل `supabase/schema_v2.sql` ثم `supabase/schema_v3.sql` ثم `supabase/schema_v4.sql` بنفس الطريقة:
   - **v2:** الموظفون والحضور والعهد وملفاتهم ومخزن الملفات.
   - **v3:** الإعدادات العامة، الهوية البصرية، ومخزن الشعار.
   - **v4:** تسجيل الدخول باسم المستخدم دون إيميل، إضافة المستخدمين بواسطة المدير، صلاحيات الحذف والتعديل في الزيارات والصيدلية.
3. من **Project Settings ← API** انسخ `Project URL` و`anon public key`، وضعهما في `config.js`.
4. من **Authentication ← Providers ← Email**: عطّل **Allow new users to sign up** (حتى لا يسجل أحد بنفسه)، واترك تسجيل الدخول بالبريد وكلمة المرور مفعلاً.
5. يمكن للمدير إنشاء المستخدمين مباشرة من داخل صفحة **الإعدادات ← + إضافة مستخدم جديد** باسم مستخدم وكلمة مرور ودون الحاجة لبريد إلكتروني، أو إنشاؤهم من لوحة Supabase.
   **أول مستخدم يُنشأ في النظام يصبح مديراً تلقائياً**.

## 2) النشر على Vercel
- الطريقة الأسهل: ارفع مجلد المشروع إلى GitHub، ثم في Vercel اختر **Add New Project** وحدد المستودع.
  **Framework Preset = Other**، وليس هناك Build Command ولا Output Directory (اتركهما فارغين).
- أو بسطر واحد من داخل المجلد: `npx vercel --prod`

## 3) الأدوار
| الدور | الصفحات |
|---|---|
| مدير | كل الصفحات + الموظفون + العهد + النسخ الاحتياطي + الاستيراد + الإعدادات |
| استقبال | الاستقبال، الزيارات (عرض وتعديل وحذف)، الحضور، التقارير |
| طبيب | الزيارات (التشخيص والوصفة)، الحضور، التقارير |
| صيدلية | الصيدلية (المخزون والصرف، التعديل والحذف وإضافة إكسل)، الحضور، التقارير |

## 4) الميزات الرئيسية الجديدة والمحدثة

### أ) الصيدلية والمخزون
- **العرض الافتراضي للمخزون:** عند فتح الصيدلية، تظهر شاشة **المخزن والتوريد** افتراضياً بدل شاشة الصرف.
- **تعديل الأصناف:** زر «تعديل» لكل صنف دوائي لتعديل الاسم، وحدة القياس، حد الطلب، وإجراء تسوية رصيد جرد مباشر.
- **حذف الأصناف:** زر «حذف» مخصص لكل صنف مع فك الارتباط الآمن بالوصفات وسجلات الحركات.
- **إضافة الأدوية بإكسل:** زر «+ إضافة بإكسل» يتيح تنزيل نموذج إكسل جاهز، ورفع ملف الأدوية لإدخال الأصناف وأرصدتها الافتتاحية آلياً مع التحقق من التكرار.

### ب) سجل الزيارات (الاستقبال والزيارات)
- **التعديل:** إمكانية تعديل أي زيارة (تاريخ الزيارة، العيادة، الطبيب، نوع الحالة، حالة المعاينة، التشخيص، الملاحظات) من شاشة سجل الزيارات أو من زيارات اليوم.
- **الحذف:** إمكانية حذف الزيارة نهائياً مع فك ارتباط أي بنود علاجية بحركات الصرف بأمان.

### ج) النسخ الاحتياطي لجميع بيانات الموقع
- زر مخصص اسمه **«النسخ الاحتياطي لجميع البيانات»** متوفر في القائمة الجانبية الرئيسية وفي صفحة الإعدادات.
- يتيح تصدير شامل لكافة جداول وبيانات النظام:
  1. **ملف Excel شامل (.xlsx):** مصنف متعدد الأوراق يحتوي على أوراق مستقلة لكل من (المرضى، الزيارات، الوصفات، الأدوية والمخزون، حركات التوريد والصرف، الموظفون، الحضور والانصراف، العهد، العيادات، الأطباء، المستخدمون، الإعدادات) مع اتجاه عربي RTL.
  2. **ملف JSON متكامل (.json):** نسخة احتياطية إلكترونية هيكلية صالحة للأرشفة وإعادة الاسترجاع.

### د) الموظفون — الإضافة بإكسل
- زر «+ إضافة بإكسل» في شاشة الموظفين.
- إمكانية تحميل نموذج إكسل معبأ بأمثلة استرشادية، وقراءة بيانات الموظفين (الاسم، الهوية، الجوال، الجنس، التخصص، مواعيد الدوام، مهلة التأخير، الملاحظات) وإضافتها دفعة واحدة مع كشف التكرار.

### هـ) إدارة المستخدمين وتسجيل الدخول بدون إيميل
- **إضافة المستخدمين بواسطة المدير:** زر «+ إضافة مستخدم جديد» في صفحة الإعدادات يتيح للمدير تحديد اسم المستخدم، الاسم الكامل، كلمة المرور، والدور المطلوب، مع إمكانية ربط الحساب بموظف محدد لتفعيل تسجيل الحضور الذاتي.
- **تسجيل الدخول بدون إيميل:** صفحة الدخول تقبل اسم المستخدم مباشرة (مثل: `ahmed` أو `dr_nour`) مع كلمة المرور دون الحاجة إلى إدخال بريد إلكتروني، مع استمرار دعم الدخول بالبريد الإلكتروني لمن يفضله.
- **إعادة تعيين كلمة المرور:** زر في جدول المستخدمين يتيح للمدير تغيير كلمة المرور لأي موظف مباشرة.

---

## 5) كيف يعمل التدفق اليومي
1. **الاستقبال:** يبحث بالاسم/الهوية/الجوال، يرى الزيارات السابقة، ويسجل زيارة اليوم لعيادة محددة. كما يمكنه تعديل أو حذف أي زيارة مسجلة بالخطأ.
2. **الطبيب:** يفتح الزيارة من صفحة **الزيارات**، يكتب التشخيص، ويختار الأدوية من قائمة المخزون.
3. **الصيدلية:** عند الدخول ترى المخزون والأرصدة مباشرة، ويمكنها التبديل إلى «صرف الوصفات» لتأكيد استلام المريض وخصم الكمية من المخزون آلياً.
4. **التقارير والنسخ الاحتياطي:** تُحسب الإحصائيات الدقيقة يومياً وأسبوعياً وشهرياً، ويمكن للمدير أخذ نسخة احتياطية كاملة للموقع في أي وقت.

## ملاحظات أمنية
- بيانات المرضى حساسة: لا تشارك مفتاح `service_role` أبداً، ولا تضعه في هذا المشروع؛ المفتاح العام `anon` محمي بقواعد RLS في Supabase.
